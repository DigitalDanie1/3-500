# 3대 500

https://3-500.vercel.app/

루트의 `index.html` 및 CSS/JavaScript 파일을 그대로 제공하는 정적 사이트입니다. 빌드 단계나 서버는 필요하지 않습니다.

## 훈련 기능

- 주 5일 분할(월 하체 · 화 가슴 · 수 등 · 목 어깨·팔 · 금 하체 볼륨), 토·일은 헬스장 밖
- 메인 종목은 5/3/1: 월 스쿼트 · 화 벤치 · 수 데드리프트 · 목 OHP. 기준값(TM) = 1RM × 90%, 주차별 65·75·85 / 70·80·90 / 75·85·95 / 디로드, 마지막 세트는 AMRAP(+), 이어서 FSL 5×5
- 사이클(4주)마다 TM 증량: 스쿼트·데드 +5kg, 벤치·OHP +2.5kg. 1RM 입력값이 바뀌면 그 사이클부터 다시 계산
- AMRAP 기록이 더 높은 1RM을 가리키면 자동 상향, 최소 횟수 미달이면 기준값 10% 하향을 안내
- 세션마다 근력 블록(5/3/1 + FSL, 휴식 2~3분)과 근비대 블록(10~15회, 휴식 45~90초) 2단 구성
- 등·어깨·가슴은 각도를 나눈 보디빌딩식 구성 + 드롭세트·레스트포즈·슈퍼셋 태그
- 모바일 요약과 주간 세션 선택
- 종목별 실제 중량·횟수·RPE 기록, 완료 체크, 휴식 타이머
- 동작 순서·흔한 실수·쉬운 대체 동작 및 외부 참고 링크
- 선택한 본중량에 맞춘 웜업 무게·세트·반복·휴식 계산
- 실측 1RM과 추정 e1RM 구분, 측정일별 그래프, 다음 점검 일정과 연기
- 회복 주차는 모든 메인 운동 55% 2 × 5와 보조 2세트로 일관되게 표시
- 달력만으로 기준 1RM을 증가시키지 않고 실제 입력 기록 사용
- 주간 실행 화면에 5/3/1 파동과 `TM = 1RM × 90% + 사이클 증량` 계산식을 그대로 노출
- 동작 가이드에 사용 근육 다이어그램(주동근·협응근)과 이 프로그램에서의 역할 추가

기존 `bigthree500.v1`, `bigthree500.week.v1`, `bigthree500.tab` 저장 키를 유지합니다. 새 세트/측정 기록은 `bigthree500.training.v2`에 저장합니다. 기록은 브라우저·기기별이며 클라우드 동기화되지 않습니다. 운동 기록 영역에서 JSON 백업을 다운로드할 수 있습니다.

## 검사

```sh
npm --prefix tests ci
npm --prefix tests test
```

계산 범위, 날짜와 점검 주기, 기존 저장값 유지, 세트 기록 복원 및 1RM 등록 흐름을 검증합니다. 테스트 의존성은 `tests/`에만 두어 기존 정적 배포 방식을 유지합니다.

## 안내 기준

8주 점검 주기와 웜업 비율은 앱의 기본 템플릿입니다. 개인별 처방이나 의무적인 검사 간격이 아닙니다. 반복 기록으로 계산한 Epley e1RM은 실측과 다르며 여유를 남긴 세트에서는 과소 추정될 수 있습니다. 동작별 안내와 1RM 점검 화면에 HPRC·ACE·NASM 등 참고 링크를 제공합니다. 외부 시범 영상 링크는 검색 결과임을 명시합니다.
